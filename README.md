# Magnetic Soft Matter Group (MSMG) Web

Official website for the Magnetic Soft Matter Group at the University of Granada.

## 🚀 Getting Started

This project is built with [Astro](https://astro.build) and [Bun](https://bun.sh).

### Commands

All commands are run from the root of the project:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `bun install`             | Installs dependencies                            |
| `bun dev`                 | Starts local dev server at `localhost:4321`      |
| `bun build`               | Build production site to `./dist/`               |
| `bun preview`             | Preview production build locally                 |

### How to propose changes
- Clone or fork the repository.
- Create a new branch for your edits.
- Make your changes and test locally with `bun dev` or `bun build`.
- Create a Pull Request with a brief explanation of the changes made.
